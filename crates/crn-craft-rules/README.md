# crn-craft-rules

**Deprecated.** Since release 0.7.0 the engine of
[CRN-craft](https://github.com/dietmarwo/CRN-craft) is the module
`crn_craft::rules` of the crate
[`crn-craft`](https://crates.io/crates/crn-craft). This crate re-exports it
(`pub use crn_craft::rules::*;`), so code written against `crn_craft_rules`
0.6, including Rust code generated by 0.6.0, keeps compiling with the same
results. New code depends on `crn-craft` and uses `crn_craft::rules`:

```toml
[dependencies]
crn-craft = "0.7"
```

```rust
use crn_craft::rules::{Control, execute, prepare};

// Validate the exact model and request bytes once; errors are coded diagnostics.
let prepared = prepare(&model_bytes, &request_bytes).expect("valid model and request");
// Run the ensemble; replicates that hit a limit are reported in the result.
let result = execute(&prepared, &Control::default()).expect("result fits the output budget");
println!("{:?}: {} events", result.termination, result.events);
```

Every item and public module of `crn_craft::rules` (`atp`, `continuous`,
`model`, `observe`, ...) is available here under the same name, and the
`crn-craft.rules-model` 0.1–0.4 and `crn-craft.rules-run` 0.1–0.6 documents
replay byte for byte. Code generated since 0.7.0 names `crn_craft::rules::`
and needs only `crn-craft`. The crate also holds the generator examples
`generate_rules_kernel`, `generate_rules_loop` and `benchmark_rules`.
