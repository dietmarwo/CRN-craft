# M10: installation and release preparation

The package builds an ABI3 Python 3.10+ wheel from the isolated PyO3 crate.
A clean Python 3.12 environment installs it and passes seven grouped acceptance
checks: exact cached/native identity, discovery, installed CLI/archive/verify,
FSP, approximate output assessment, importer and observable execution. Built-in
models ship as package resources. Linux x86_64 is executed locally; macOS/Windows
wheel acceptance is a manual CI workflow, not a claimed local pass.

Source distribution and wheel build with exact lockfiles. No package index,
GitHub branch/tag or remote repository is changed. Owner-controlled publishing
and additional platform validation remain separate actions.

The first clean-wheel check used X instead of the example's A species in an
FSP bound; the fixture now uses the actual model. The first source glob used
`**`, which did not include recursively nested files; `**/*` and sdist-only
entries make the intended source/license/data contents explicit. Rebuilds from
extracted source are part of final packaging verification.

Discovery is version 0.5 and lists the extra commands. The original eleven schema
snapshots stay unchanged; fsp-result, tau-request and tau-result are new 0.1 types.
The version-independent checksum tamper test preserves equal file length and
still forces checksum verification rather than relying on semantic rejection.
