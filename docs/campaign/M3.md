# M3: finite state projection

Reachable-state BFS builds a row-oriented sparse generator. Positive transitions
outside the inclusive box go to an explicit absorbing sink; null reactions do
not alter the generator. Population safety limits remain errors inside the box.
No probability is reflected or renormalized. The original FSP run/0.1 contract
is consumed by `crn-craft fsp MODEL RUN [--cancel-file PATH]`; the new result is
`crn-craft.fsp-result/0.1`, with a Rust-generated schema (`describe fsp-result`).

Uniformization splits each interval so lambda*dt <= 16. Each Poisson series is
stopped using a geometric tail majorant. Per-step allocations sum to the run's
tolerance. The reported sink estimate, discarded-series bound, estimated actual
discarded weight, mass defect and roundoff mass residual are separate. Ordinary
f64 roundoff is not certified. A small sink does not bound unbounded moments;
reported moments are unnormalized projections of the retained law.

Limits: 100000 reachable states, 2000000 edges, 200000000 charged work units,
256 MiB conservative workspace reservation, caller output budget, wall deadline
and cooperative cancellation. Interrupted/limited solves fail explicitly and
never return a complete distribution from an incomplete generator.

Validation: three Rust tests (multiple analytic subcases), independent SciPy
matrix-exponential comparisons on four reviewed nonlinear CME fixtures plus
DSMTS 001-01 and 002-01, analytic DSMTS moments and upstream rounded means.
The external DSMTS revision and six source hashes are recorded; LGPL inputs
are not copied into the MIT numerical engine. All 16 independent checks pass;
maximum per-state/sink discrepancy is 4.07e-14, below the frozen 2e-12 target.
The first Rust test run failed because new fixtures requested no outputs, which
the existing contract rejects; fixtures now request mean. That failed log is kept.
