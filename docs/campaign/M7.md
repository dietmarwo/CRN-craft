# M7: optional BDF, sensitivities, fitting and conservative screening

`integrations/diffsol` pins diffsol 0.18.0, using native closures and Nalgebra BDF,
without DiffSL/LLVM. It has its own lockfile and Rust 1.89 requirement; the default
core remains Rust 1.85. `crn-diffsol MODEL REQUEST` returns ODE result/0.1, including
raw-parameter forward sensitivities. New core Kinetics evaluates analytic state
and parameter Jacobians, checked against independent central differences.

The count-kinetic convention is macroscopic c*product(y^order/order!), not the
nonlinear stochastic mean. Production-only Hill and substrate-consuming MM laws
have explicit smooth extensions; discrete gates without a smooth extension are
rejected. Negative/domain/singular states fail, with no hidden clipping. Limits
are 64 species, 32 parameters, 256 reactions and 10000 requested times.

The predeclared 16 BDF/analytic/DOP853/sensitivity comparisons pass. The synthetic
`examples/circuit/fit_ode.py` uses pinned fcmaes-rust 0.2.1 and SQP-craft 0.17.0:
64 BiteOpt calls, explicit best-point start, derivative checks, native forward
sensitivities and an independent analytic re-evaluation. Loss falls from 0.5901
to 4.97e-20 in 94 total native propagations including checks.

`screen.py` never removes a topology based on its deterministic trajectory.
Both the three-gene ring and the paper-defined Vilar control (delta_R=0.05) receive
eight held-out SSA paths. The measured horizons give mostly ambiguous/noisy
spectral diagnoses; no universal detection accuracy or noise-driven-oscillation
proof is inferred. The nonzero-allocation guarantee, rather than a hard ODE filter,
prevents deterministic screening false negatives by construction. Source: Vilar,
Kueh, Barkai & Leibler (2002), https://pubmed.ncbi.nlm.nih.gov/11972055/.
The 16 reaction equations/parameter values are mathematical model definitions;
no simulator source was copied.

The first fit driver used `activeset`; the installed package requires `active-set`.
The failed log is kept. The default core's derivative tests and optional clippy pass.
