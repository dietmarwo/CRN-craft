# M8: explicit import subsets

Python module `crn_craft.importers` provides versioned import reports with source
SHA-256, transformed model, convention and provenance. Both routes call the native
strict model validator. Imported constant parameters are folded into literal rates;
parameter fitting requires explicitly promoting selected literals afterwards.

SBML: Level 3 Version 2 Core, one fixed unit-size compartment, integer item amounts,
substance-only non-boundary species, irreversible expanded reactions and polynomial
MathML jump propensities. Exact rational polynomial algebra verifies proportionality
to the stochastic binomial factors, including the homodimer divisor. A deterministic
k*A^2 law is rejected as a stochastic homodimer law. Rules, events, conversions,
local parameters, extensions, unsupported units, reversible channels, concentrations,
DTDs/entities and unsupported MathML receive CRN-E090. This is a numerical subset
importer, not a complete SBML conformance validator. Specification reference:
https://sbml.org/documents/specifications/level-3/version-2/core/.

BioNetGen: already-expanded .net parameter/species/reaction/groups blocks, finite
scalar arithmetic, repeated species indices and explicit binomial versus
falling-factorial coefficient conversion. Species patterns and groups remain
provenance; rules/functions are not expanded or executed. Python eval is never used.
The caller must supply the rate convention; it is not guessed from a filename.

29 checks pass normally and under -O: accepted dimer and both .net conventions,
unsupported/unsafe/ambiguous semantic rejection probes, source-pattern retention,
coefficient overflow/positive-underflow rejection and independent coefficient checks.
This small fixture set does not replace the
full SBML or BioNetGen upstream test suites.

Example:
`python -m crn_craft.importers sbml source.xml imported.json --convention stochastic_count_propensity`.
For .net use `bng-net` and `--convention binomial` or `falling_factorial`.
The destination must be new; the report's `model` is the native model document.

Final rejection probes also cover undefined initial amounts, parameter values,
compartment sizes and reversibility, plus non-UTF8/UTF16 XML. These are not replaced
by silent zero/one defaults. The polynomial subset is limited to 64 species,
degree eight, 4096 products and bounded exact rational arithmetic.
