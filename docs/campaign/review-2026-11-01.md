## Validation limitations

- Timings are from one shared 2-vCPU host; P14–P16 were measured on a base
  that still contained P13 (the R13 run measures the revert separately).
- P20 was judged on process time by an amendment recorded before its
  measurement, because the work it removes ran outside the core timer.
- `compare_tau_samplers.py` was added after the P19 declaration and is
  supplementary evidence, not one of P19's gates.
- The topology screen's horizon was raised after observing an ambiguous
  classification at the previous horizon; the screen is an illustration.
- `check_jobs.py` needs the optimization-jobs runner and is not run in CI;
  the integrations are not built in CI (see the technical report).
- The ODE integration has no step or wall-time budget.
- The rebop comparison includes rebop's Python overhead and uses independent
  random streams; it compares cost, not paths.
