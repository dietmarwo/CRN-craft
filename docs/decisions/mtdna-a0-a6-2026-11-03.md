# mtDNA A0–A6 validation protocol

Base a34484b. A0 reproduces the stated equations with deterministic mutation
channels. Copy-number target 1000, 25,920 hours, no stop by default, and
competition D = wt + sm × (mt + mtAdv). The existing clone fixture remains
the lumping reference. The reported Java and rebop times are external baselines.

Before timing, require the following.

- Exact-law fixture K=20 at times 1, 3 and 10, with 32,768 paths per
  backend and independent seed 20261103 for the new ensemble. Compare the
  three marginal CDFs at each time to the existing independent CME oracle.
  Family alpha 0.001 over 36 marginal tests (clone, tree, static Direct,
  next reaction). Use sqrt(log(2*36/0.001)/(2*32768)).
- Check complete numerical payload equality across 1 and 20 workers,
  ignoring only the request hash. Exercise cancellation and event/output
  budgets. Observation counters, episodes and integrals must agree with
  reconstruction from the same full event log. An observer that continues
  must preserve all numerical payloads.
- Approximate tau at epsilon 0.03 and 0.01 uses the same fixture, horizons
  and sample count. Use two independent samples against exact SSA and the
  conservative two-sample DKW triangle bound with family alpha 0.001
  over 24 comparisons. Check three CDFs at three times, terminal mutant
  fraction, terminal takeover indicator, and first passage to at least
  50% mutant fraction, including the never-hit mass. Require the smaller
  epsilon to pass all comparisons and every sample to be nonnegative.
- For ATP thinning, use a single time-varying birth channel with constant
  wild-type count. Compare counts to the Poisson law with integrated
  saturating ATP intensity (three times, same N, family alpha 0.001).
  Check cancellation and bounds over increasing and decreasing ATP.
- Compare rules and network next reaction with independent Poisson laws
  on immigration/death and time-reuse fixtures. Report timings on a sparse
  fixture as well as mtDNA.
- Benchmark identical report grids and work budgets, one and twenty workers.
  Record quota, full event counts and wall times. Run the full 10,000-path
  case on the best validated exact method. A3 target is at least 2× event
  throughput versus tree Direct on the same host. Matching the reported
  11 s requires the original comparator code, solver, stop rules and host.
